## 🇯🇵 自己紹介 / 研究への情熱

こんにちは！**kotobuki375** です。

このウェブログは、私の大学での学び、アルゴリズム競プロ（Competitive Programming）、精度高く修士課程への進学を準備する日々の挑戦を記録する**「秘密基地」**です。

### 🌟 バックグラウンドとエピソード
実は、このブログを開設したのは**中国の大学入試（高考）の数週間前**でした。当時、私のカバンは入試の模擬試験問題ではなく、大学レベルの『離散数学』の証明手稿で溢れていました。周囲が受験勉強に追われる中、私はコンピュータサイエンスの根本的な美しさに魅了され、自らこの環境を構築しました。

大舞台（本番）に強い精神力を活かし、現在は**モダンC++（Modern C++）**の標準ライブラリ（STL）や低レイヤのメモリメカニズムへの理解を深めながら、日々アルゴリズムの腕を磨いています。
