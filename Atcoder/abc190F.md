# AtCoder ABC190F - Permutation Method (全排列逆序對遞推)

## 📌 題目概述
給定一個長度為 $N$ 的排列 $A = (a_0, a_1, \dots, a_{N-1})$，它是 $\{0, 1, \dots, N-1\}$ 的一個全排列。
我們需要分別求出 $k = 0, 1, \dots, N-1$ 時，將排列向左循環平移 $k$ 位後得到的新序列的**逆序對數**。

---

## 💡 核心算法思想：貢獻流思維與局部增量更新

如果對每一個 $k$ 都盲目地重新計算一遍逆序對，即便使用歸並排序或樹狀數組，總複雜度也會達到 $O(N^2 \log N)$ 甚至 $O(N^2)$，在 $N = 3 \times 10^5$ 的數據範圍下面必然超時（TLE）。

敏銳觀察「向左循環平移 $1$ 位」的物理畫面：**傳統上就是將當前序列的「排頭元素」挪到了「排尾」，而中間其他所有元素的相對先後順序完全沒有發生改變。**

由於題目給定的輸入是一個極其霸道的條件——**$0 \sim N-1$ 的全排列**，整個系統的成員完全透明。這意味著，一個元素在全局生態位中「比它小的有多少個」、「比它大的有多少個」是**絕對靜態已知**的。

因此，我們不需要推倒重來，只需要在初始逆序對總賬的基礎上，精準鎖定位移元素對總賬造成的**局部增量（$\Delta$）**，即可在 $O(1)$ 的時間內完成狀態的遞推記賬。

---

## 📐 核心命題的嚴密數學證明

### 📝 命題陳述
設 $N$ 為正整數，$\pi = (x, a_2, a_3, \dots, a_N)$ 是 $\{0,1,\dots,N-1\}$ 的一個排列。將 $\pi$ 的第一個元素 $x$ 移到末尾得到新排列 $\pi' = (a_2, a_3, \dots, a_N, x)$。記 $\operatorname{inv}(\pi)$ 為 $\pi$ 的逆序對數，則：

$$\operatorname{inv}(\pi') = \operatorname{inv}(\pi) - x + (N-1-x)$$

### 📐 分類窮舉證明

**引入輔助集**：設 $S = \{0,1,\dots,N-1\} \setminus \{x\}$，即整個全排列中除去元素 $x$ 後的其餘元素集合。

在排列變換（排頭變排尾）的過程中，所有元素對的相對位置及逆序貢獻可以精細地劃分為以下三類：

#### 1. 移位前：包含 $x$ 且 $x$ 在左側的元素對
在原排列 $\pi$ 中，由於 $x$ 占據首位，對於任意 $y \in S$，元素對必定呈現為 $(x, y)$（$x$ 在左，$y$ 在右）。此類元素對總數共有 $|S| = N-1$ 個。
* 若 $y < x$，則 $(x, y)$ 構成一個逆序對（左大右小）。
* 若 $y > x$，則 $(x, y)$ 構成一個正序對，對逆序數無貢獻。

> **全排列特徵應用①**：由於 $\pi$ 是 $0 \sim N-1$ 的全排列，在集合 $S$ 中，數值上比 $x$ 小的整數共有 $\{0, 1, \dots, x-1\}$ 恰好 **$x$ 個**。因此，在原排列中，由 $x$ 貢獻的逆序對數量精準為 $x$ 個。當 $x$ 移走後，這 $x$ 個逆序對**瞬間集體消失**。

#### 2. 移位後：包含 $x$ 且 $x$ 在右側的元素對
在新排列 $\pi'$ 中，$x$ 被強行移至末尾。此時對於任意 $y \in S$，原本的 $(x, y)$ 全部物理翻轉為 $(y, x)$ 對（$y$ 在左，$x$ 在右）。
* 若 $y > x$，則 $(y, x)$ 構成一個**新誕生的逆序對**（左大右小）。
* 若 $y < x$，則 $(y, x)$ 演變為正序對，無貢獻。

> **全排列特徵應用②**：集合 $S$ 中數值比 $x$ 大的整數集合為 $\{x+1, x+2, \dots, N-1\}$，其元素個數精準為 **$(N-1) - x$ 個**。因此，當 $x$ 成為排尾時，整個序列瞬間憑空**新增了 $(N-1-x)$ 個**逆序對。

#### 3. 獨立性：不包含 $x$ 的其餘任意元素對
考慮任意不包含 $x$ 的元素對 $(u, v)$，其中 $u, v \in S$。
在移動操作中，我們僅僅將 $x$ 從絕對頭部抽離並置於絕對尾部，其餘所有元素依次向左平移，**它們彼此之間的相對先後次序並未發生任何改變**。

即：若 $u$ 在原排列 $\pi$ 中位於 $v$ 的左側，則在 $\pi'$ 中 $u$ 依然必然位於 $v$ 的左側。

> **物理隔離結論**：不包含 $x$ 的所有內部元素對，其逆序與正序狀態被完全“冰封”，其對全局逆序數的貢獻在變換前後為**絕對常數**。

### 📊 賬本總量更新

綜上所述，新序列的逆序對總數等於原序列的逆序對總數，**減去**因 $x$ 移走而集體消失的逆序對（共 $x$ 個），**加上**因 $x$ 墊底而全新孵化出的逆序對（共 $N-1-x$ 個），其餘內部貢獻守恒：

$$\operatorname{inv}(\pi') = \operatorname{inv}(\pi) - \underbrace{x}_{\text{消失項}} + \underbrace{(N-1-x)}_{\text{新增項}}$$

$$\square$$

此證明不依賴於序列內部的具體順序（中間項即便極度混亂也完全不影響結論），僅使用排列的全局性質（全排列的計數特徵）和移動操作對元素相對順序的影響。成功將一個動態維護問題，物理降維成了 $O(1)$ 的代數常數遞推。

## 🛠️ 終極無瑕疵 C++ 原始碼

本代碼包含兩大競賽專用底層優化：
1. **解除流同步**：`ios::sync_with_stdio(false); cin.tie(0);` 極大提升 $I/O$ 效率。
2. **避免緩衝區強刷**：使用 `"\n"` 代替 `endl`，防止多達 $3 \times 10^5$ 行輸出時因頻繁刷新系統緩衝區而導致超時（TLE）。
```cpp
#include<iostream>
using namespace std;

int n;
// 竞赛大坑规避：把数组大小开到 300005，安全锁死 3 * 10^5 的最大数据范围
int q[300005], tmp[300005], a[300005];
long long res = 0;

// 归并排序求初始序列的逆序对数
void merge_sort(int q[], int l, int r){
    if(l >= r) return;
    int mid = (l + r) >> 1;
    merge_sort(q, l, mid);
    merge_sort(q, mid + 1, r);
    int i = l, j = mid + 1, k = 0;
    while(i <= mid && j <= r){
        if(q[i] <= q[j]) tmp[k++] = q[i++];
        else{
            res += mid - i + 1; // 批量统计逆序对
            tmp[k++] = q[j++];
        }
    }
    while(i <= mid) tmp[k++] = q[i++];
    while(j <= r) tmp[k++] = q[j++];
    for(int i = l, j = 0; i <= r; i++, j++) q[i] = tmp[j];
    return;
}

int main(){
    // 开启 C++ 极速输入输出外挂，防止因大量数据打印导致 TLE
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n;
    for(int i = 0; i < n; i++){
        cin >> q[i];
        a[i] = q[i]; // 备份原数组，用于后续依次寻找“排头兵”
    }
    
    // 1. 计算初始总账
    merge_sort(q, 0, n - 1);
    cout << res << "\n"; 
    
    // 2. 依次进行 O(1) 的局部增量记账更新
    for(int k = 0; k < n - 1; k++){
        long long x = a[k]; // 找出下一个要挪到尾巴的人
        res = res - x + ((n - 1) - x); // 严密的数学推导核心公式
        cout << res << "\n"; 
    }
    return 0;
}
